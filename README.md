# Uber Trip Analysis Dashboard

## Overview
An interactive Power BI project designed to analyze Uber trip data and explore booking trends, booking amounts, trip distances, trip durations, and demand patterns.

## Objectives
- Analyze total bookings and booking amounts.
- Evaluate average booking amounts and trip distances.
- Identify peak and off-peak demand periods.
- Compare vehicle types, payment methods, and trip patterns.
- Explore pickup and drop-off locations.

## Dashboard Pages

### 1. Overview Analysis
- Key performance indicators (KPIs)
- Payment type and day/night trip analysis
- Vehicle type performance
- Daily bookings and location analysis

### 2. Time Analysis
- Pickup-time analysis using 10-minute intervals
- Booking trends by day of the week
- Hour-by-day demand heatmap

### 3. Trip Details
- Detailed trip records
- Drill-through analysis
- Full-data view using bookmarks

## Tools and Technologies
- Microsoft Power BI Desktop
- DAX (Data Analysis Expressions)
- Data Modeling
- Interactive Data Visualization

## Key Features
- Dynamic measure selection
- Interactive slicers and tooltips
- KPI cards and conditional formatting
- Drill-through navigation and bookmarks

## Repository Contents
- `Uber_Trip_Analysis.pbix` — Power BI report
- `screenshots/` — Dashboard screenshots

## How to Use
1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Refresh the data if the original data source is available.
4. Explore the report pages and interactive visuals.
